# Аукціон ресурсів (Завдання 15)

Вебсайт, на якому учасники обмінюються їжею, водою й повітрям: виставляють лоти, роблять ставки та викуповують лоти.

## Запуск

1. Створіть базу даних у PostgreSQL (наприклад, через pgAdmin або `psql`): `CREATE DATABASE auction;`
2. У корені проєкту один раз завантажте залежності: `go mod tidy`
3. Задайте адресу бази та запустіть сайт (PowerShell):

```powershell
$env:DATABASE_URL = "postgres://postgres:ПАРОЛЬ@localhost:5432/auction"
go run ./auction
```

4. Відкрийте http://localhost:8080

Таблиці створюються автоматично під час першого запуску. Порт можна змінити змінною `PORT`.

## Тести

```powershell
go test ./auction/
```

Тести з базою даних запускаються лише тоді, коли задано окрему тестову базу (усі дані в ній очищуються):

```powershell
$env:TEST_DATABASE_URL = "postgres://postgres:ПАРОЛЬ@localhost:5432/auction_test"
go test -v ./auction/
```

## Правила

- Під час реєстрації учасник сам вказує, скільки в нього їжі, води й повітря (наприклад, переносить із квесту).
- Лот: кількість одного ресурсу, стартова ціна в іншому ресурсі, необов'язкова викупна ціна, тривалість. Ресурси лота резервуються одразу.
- Ставка має бути не меншою за стартову ціну і більшою за поточну. Ресурси ставки резервуються й повертаються, коли її перебивають.
- Коли час виходить, лот отримує учасник із найбільшою ставкою. Якщо ставок не було, ресурси повертаються продавцю.
- Викуп за викупною ціною доступний, поки найбільша ставка не перевищила половину викупної ціни.
